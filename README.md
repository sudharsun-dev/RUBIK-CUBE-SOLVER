# 🧩 3D Rubik's Cube Solver

A **3D Rubik's Cube Solver built from scratch in C++**, combining **data structures, algorithms, 3D mathematics, OpenGL graphics, interactive controls, animation, and automated solving**.

The goal of this project is to create a fully interactive 3×3×3 Rubik's Cube that users can manipulate in 3D, scramble, and automatically solve while watching the solution being animated move by move.

---

## 🎯 Project Goal

The project combines:

- C++
- Data Structures & Algorithms
- 3D Mathematics
- OpenGL
- Computer Graphics
- Cube State Management
- Search Algorithms
- GUI Development
- Animation

The final application will allow users to:

- View a 3D Rubik's Cube
- Rotate and inspect the cube
- Perform standard cube moves
- Generate random scrambles
- Undo moves
- Reset the cube
- Automatically solve the cube
- View the solution sequence
- Watch the solution execute through 3D animations

---

## 🚀 Features

### 🧩 Cube Engine

- 3×3×3 Rubik's Cube representation
- Correct cube state management
- Standard cube moves
- Prime moves
- Double moves
- Move history
- Undo

- Cube state validation
